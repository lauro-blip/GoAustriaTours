# Image credits

The only photographs so far are the three home hero images (files in `public/images/hero/`), from Wikimedia Commons under CC BY / CC BY-SA, which REQUIRE attribution: add a visible credit (e.g. footer or About page) before launch. Every other image slot still shows a placeholder.

Rules for adding images: use only images free for commercial use with no licence fee (Unsplash, Pexels, Pixabay: check each image's licence), public domain, or images you supply. Never take images from competitor sites, Google Images, Pinterest, social media or other travel companies; avoid recognisable logos, trademarks or people/private property needing a release. Download and optimise into the project (upload via Admin > Media or on the package/tour type form); never hotlink. Add a row below for every image.
